# StreamNest 0.23.0

Search movies, series and anime directly from Home.

- Desktop: a search field on Home, with grouped matches and Previous/Next result pages.
- Android/Google TV: the Home search icon opens search immediately, without asking for a category.
- Saved catalogs appear first; independent services add results. One failed service does not block available matches, and old responses cannot replace newer searches.
- Clearing search restores Home recommendations. Search does not change your synced recommendation list or viewing history.

Android/Google TV: universal, ARM32 and ARM64 APKs. Windows: standalone installer and portable package; no Popcorn Time installation required. Windows builds remain unsigned.

Owner confirmed TV universal-APK next-episode preload and latest physical Home layout passed. Catalog and playable-source availability depend on external services.
