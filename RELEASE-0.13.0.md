# StreamNest 0.13.0

- Resume movies, series and anime across source/quality changes.
- Optional encrypted resume sync across Android, Google TV and Windows using a private pairing code/QR; no StreamNest login.
- Offline local progress, deliberate rewind handling and completion tracking.
- Sharper Windows app-registration icon with ten native sizes and less empty padding.
- Intro/credits controls verified using decoded playback fixtures; live timestamp coverage depends on title and release.

See WATCH-SYNC.md for pairing and privacy details. Android still requires the system installation confirmation. Windows is a standalone preview.
